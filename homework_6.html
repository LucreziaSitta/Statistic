Ex. 1
Riemann and Lebesgue integration

Riemann: partition the domain

Cut [a, b] into N subintervals of width Δx = (b − a)/N and add up the rectangles. Here the tag is the midpoint xᵢ* of each subinterval:

∫ f ≈ Σᵢ f(xᵢ*) · Δx

Lebesgue: partition the range

Cut the values [y_min, y_max] into M levels yⱼ and measure the preimage of each level, Eⱼ = {x : yⱼ ≤ f(x) < yⱼ₊₁}:

∫ f ≈ Σⱼ yⱼ · μ(Eⱼ)

The measure μ(Eⱼ) is the total length of the points of the domain whose value falls in level j. It is estimated by counting how many of S sample points land in each level: μ(Eⱼ) ≈ (b − a)·Sⱼ/S. Riemann asks "what is the value here?", Lebesgue asks "where does the function take this value?".

What the comparison shows
  • Riemann-integrable functions give the same value with both methods. For every continuous or piecewise continuous function in the table the two numbers approach the exact integral; for bounded functions whose discontinuities have measure zero, the Riemann and Lebesgue integrals coincide.
  • Accuracy and convergence. For smooth functions the midpoint Riemann sum has error proportional to 1/N² (slope −2 in the chart), while the Lebesgue sum from below has error proportional to 1/M (slope −1): each level is replaced by its lower value. Lebesgue is instead exact for step functions for every M, because their few values fall exactly on the levels. Riemann is exact only if the jump at 0.5 falls on a subinterval boundary (N even); with N odd the subinterval containing the jump gets the wrong height and the error is proportional to 1/N.
  • Efficiency. Riemann needs N evaluations and a sum. The Lebesgue approach needs many sample points to estimate the measures, plus a pass to sort them into levels: more work for the same accuracy. Its strength is theoretical, not computational.
  • 1/√x is unbounded. Both methods converge slowly: Riemann because the rectangles near 0 miss part of the area (error about 1/√N), Lebesgue because uniform levels on a range that goes to infinity are coarse exactly where most of the measure is.
Functions for which the two approaches behave differently

Dirichlet function

f = 1 on the rationals, 0 on the irrationals. Every subinterval contains both, so the Riemann sum is 1 with rational tags and 0 with irrational tags: it does not converge to a single value and the Riemann integral does not exist. For Lebesgue the rationals are countable, so μ(f⁻¹(1)) = 0 and μ(f⁻¹(0)) = 1: the integral is 0 · 1 + 1 · 0 = 0.

Thomae's function

f(p/q) = 1/q in lowest terms, 0 on the irrationals. It is discontinuous at every rational but continuous at every irrational, so its discontinuities have measure zero and it is Riemann-integrable, with integral 0. The midpoint sums tend to 0 slowly; Lebesgue gives 0 directly, because the set where f > 0 has measure zero.

In the computer every floating-point number is rational. For these two functions the page therefore uses exact fractions: the Riemann tags are the rationals (2i + 1)/(2N), and the Lebesgue sample points are x = (k + θ)/S with θ = (√5 − 1)/2, which are irrational numbers in exact arithmetic, so f = 0 there.

Ex. 2
Why the normal CDF needs numerical methods

The standard normal CDF is

Φ(x) = P(Z ≤ x) = (1/√(2π)) ∫₋∞ˣ e^(−t²/2) dt

The constant 1/√(2π) makes the total area 1. Following Hogg–McKean–Craig §3.4: with I = ∫₀^∞ e^(−x²) dx, I² = ∫₀^∞∫₀^∞ e^(−(x²+y²)) dx dy, and in polar coordinates (dx dy = r dr dθ) this is π/4. So I = √π/2, and the substitution z = √2·x gives ∫ φ = 1.

Liouville's theorem: no elementary antiderivative

An elementary function is built from polynomials, exponentials, logarithms, roots and trigonometric functions with finitely many operations. Liouville's theorem (1835) says that if g and h are rational functions and ∫ g·e^h has an elementary antiderivative, then it must be of the form R·e^h with R rational. For e^(−x²) (g = 1, h = −x²) differentiating gives

(R·e^(−x²))′ = e^(−x²)  ⇒  R′(x) − 2x·R(x) = 1
  • R has no poles: a pole of order k in R becomes a pole of order k + 1 in R′, which nothing on the left can cancel, while the right side has none. So R is a polynomial.
  • No polynomial works: if deg R = d, then deg(R′ − 2xR) = d + 1 ≥ 1, but the right side 1 has degree 0. Contradiction.

Hence e^(−x²), and with x = t/√2 also e^(−t²/2), has no elementary antiderivative, and Φ cannot be written with elementary functions.

The error function

A special function is defined to fill the gap: erf(z) = (2/√π) ∫₀ᶻ e^(−u²) du. With u = t/√2:

Φ(x) = ½ · [1 + erf(x/√2)]

This is an exact representation, but it only moves the problem: erf is itself defined by the same integral, and to get its digits a computer still needs an algorithm, either a quadrature, a series or an approximation. That is the subject of the next step.

Ex. 2
Computing Φ(x): four methods

A · Simpson's rule

Φ(x) = ½ + ∫₀ˣ φ(t) dt, integrated with n subintervals (n even); for x < 0 by symmetry. Error proportional to 1/n⁴.

B · Power series of erf

erf(z) = (2/√π) Σ (−1)ᵏ z^(2k+1) / (k!(2k+1)). Alternating terms: for large z they grow before cancelling and digits are lost.

C · Abramowitz–Stegun 7.1.26

A fixed formula for erf with a polynomial in t = 1/(1 + 0.3275911·z): one exponential, maximum error 1.5·10⁻⁷.

D · Proposed method

For |x| < 2.5 the series with positive terms Φ(x) = ½ + φ(x)·(x + x³/3 + x⁵/(3·5) + …), with no cancellation. For |x| ≥ 2.5 the continued fraction of the tail, 1 − Φ(x) = φ(x)/(x + 1/(x + 2/(x + 3/(x + …)))), 60 levels.

Conclusions

Simpson's rule is simple and converges fast (error ∝ 1/n⁴), but every value costs n + 1 exponentials. The alternating erf series is exact in theory but loses digits through cancellation as |x| grows. A&S is the fastest and is enough for 6–7 digits, as in statistical tables. The proposed method combines two expansions that only add positive quantities, so it reaches machine precision (about 10⁻¹⁶) at every point with a few dozen operations, and the continued fraction also keeps the tiny tail probabilities 1 − Φ(x) accurate. This is the same idea used by numerical libraries: no single formula is good everywhere, so different expansions are used in different ranges.
